Створення DEB-пакета

Завдання 4. Порівняння процесів створення RPM та DEB-пакетів

RPM та DEB  це формати програмних пакетів, які використовуються для встановлення, оновлення та видалення
 програм у Linux. Основна відмінність між ними полягає в дистрибутивах, для яких вони призначені,
 а також в інструментах і способах створення пакетів. RPM використовується переважно в Fedora,
 RHEL та CentOS, а у DEB  Debian, Ubuntu та Linux Mint.

Для створення RPM-пакета використовується утиліта rpmbuild. Основним файлом налаштування є SPEC-файл,
 який містить інформацію про пакет, його залежності, інструкції зі збирання та встановлення.
Щоб зібрати RPM-пакет, використовують утиліту rpmbuild. Уся потрібна інформація зберігається в одному
 SPEC-файлі, там описано сам пакет, його залежності, а також команди для збирання та встановлення.
 Також у SPEC-файлі можна задати службові скрипти, які запускаються до чи після встановлення
 й видалення пакета.

З DEB трохи по інщому, пакет збирають за допомогою dpkg-buildpackage та debhelper,
 а налаштування розкладено по кількох файлах у директорії debian/. Файл control містить опис
 пакета та його залежності, changelog зберігає історію змін, rules описує, як саме збирати пакет,
 а install визначає, куди потрапляють файли під час встановлення.

Додаткові дії в RPM виконуються через секції %pre, %post, %preun та %postun. У DEB для цього
 є окремі скрипти preinst, postinst, prerm та postrm.
Встановлювати RPM-пакети можна через rpm або dnf, а DEB-пакети — через dpkg або apt.
